The design for a PCB board that features an ESP32-S3-Wroom-1, a voltage regulator, an audio chip, pads for 7 servos, and pads for 2 smart LEDs. There is also a circit for cutting power from the battery when the ESP32 turns off using a MOSFET and transistor. This will be the brain for the entire project.
